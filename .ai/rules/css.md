# Css

## MD3 admin palette defined in @theme
The admin UI follows a Material Design 3 palette defined as CSS vars in app.css @theme: --color-primary #006194, --color-primary-container #007bb9, --color-surface #f8f9ff, --color-surface-card #fff, --color-surface-subtle #f1f5f9, --color-surface-container-* #e5eeff/#eff4ff/#dce9ff, --color-on-surface #0b1c30, --color-on-surface-variant #3f4850, --color-status-info/success/warning/error (#0284c7/#16a34a/#ea580c/#dc2626). Legacy tokens (ink, inkmuted, stone-*, moss-*) are aliased to these so old classes still resolve.
